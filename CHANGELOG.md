## [v0.1.0] - 2024-04-26

### Highlights

- Initial release of ProductGraph event ingestion service
- PostgreSQL-based Starter architecture with Row-Level Security for multi-tenancy
- OTel-compatible event schema with 40+ fields

### Added

- Event ingestion HTTP service (`POST /v1/events`) with batch support (max 1000 events) ([`17c3b16`](https://github.com/plexusone/productgraph/commit/17c3b16))
- Health (`GET /health`) and readiness (`GET /ready`) endpoints ([`17c3b16`](https://github.com/plexusone/productgraph/commit/17c3b16))
- CORS middleware for development ([`17c3b16`](https://github.com/plexusone/productgraph/commit/17c3b16))
- OTel-compatible event schema with 40+ fields across 8 namespaces ([`ba46b7e`](https://github.com/plexusone/productgraph/commit/ba46b7e))
- Event types: page.view, page.leave, ui.click, ui.input, ui.scroll, ui.submit, state.change, api.request, api.response, journey.step, error, performance, custom ([`ba46b7e`](https://github.com/plexusone/productgraph/commit/ba46b7e))
- Ent ORM schemas for Organization, Project, Event, Session, Journey ([`3307638`](https://github.com/plexusone/productgraph/commit/3307638))
- PostgreSQL Row-Level Security (RLS) for multi-tenancy via `org_id` ([`3307638`](https://github.com/plexusone/productgraph/commit/3307638))
- Database indexes optimized for time-series queries ([`3307638`](https://github.com/plexusone/productgraph/commit/3307638))
- Docker Compose development environment with PostgreSQL 16 ([`d477c8a`](https://github.com/plexusone/productgraph/commit/d477c8a))
- Makefile with build, test, generate, and migrate commands ([`3c42542`](https://github.com/plexusone/productgraph/commit/3c42542))
