## [v0.3.0] - 2026-06-20 ([`0804bba`](https://github.com/plexusone/productgraph/commit/0804bba))

### Highlights

- Product catalog modeling with Capability and Feature entities
- Replace Project entity with Product for clearer domain modeling
- CLI tooling for capability catalog management

### Breaking

- Project entity renamed to Product; `project_id` field renamed to `product_id` in event payloads and database schemas ([`f6a43b7`](https://github.com/plexusone/productgraph/commit/f6a43b7))

### Added

- Product entity replacing Project with capabilities edge ([`f6a43b7`](https://github.com/plexusone/productgraph/commit/f6a43b7))
- Capability entity for modeling major functional areas within a Product ([`f6a43b7`](https://github.com/plexusone/productgraph/commit/f6a43b7))
- Feature entity for specific functionality within a Capability ([`f6a43b7`](https://github.com/plexusone/productgraph/commit/f6a43b7))
- Journey can now optionally link to a Feature via `feature_id` ([`f6a43b7`](https://github.com/plexusone/productgraph/commit/f6a43b7))
- Capability catalog types (`CapabilityCatalog`, `Capability`, `Feature`) for import/export ([`5010c77`](https://github.com/plexusone/productgraph/commit/5010c77))
- `schemagen` CLI tool for JSON Schema generation from Go types ([`68b5598`](https://github.com/plexusone/productgraph/commit/68b5598))
- Embedded JSON Schema for capability catalog validation ([`81c2bee`](https://github.com/plexusone/productgraph/commit/81c2bee))
- `catalog2md` CLI tool for converting catalogs to markdown ([`45c0de8`](https://github.com/plexusone/productgraph/commit/45c0de8))
- `catalogctl` CLI with validate and convert commands ([`0804bba`](https://github.com/plexusone/productgraph/commit/0804bba))

### Changed

- Event schema: `ProjectID` renamed to `ProductID` ([`34b7c9d`](https://github.com/plexusone/productgraph/commit/34b7c9d))
- Analytics adapter updated for product_id field ([`01e2867`](https://github.com/plexusone/productgraph/commit/01e2867))

### Dependencies

- github.com/spf13/cobra v1.10.2 ([`a7740d6`](https://github.com/plexusone/productgraph/commit/a7740d6))
- github.com/invopop/jsonschema v0.14.0 ([`a7740d6`](https://github.com/plexusone/productgraph/commit/a7740d6))
